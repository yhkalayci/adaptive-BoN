# Unknown-reward, unknown-cost Pandora manuscript

The current manuscript is [main.pdf](main.pdf). It defines Pandora's box with
unknown reward and random cost distributions, states the learned-threshold
theorem, explains Bradley--Terry and isotonic reward calibration, and reports
Alignment and Coding experiments with deployable and oracle fixed baselines.

## Selected simple policies

- Alignment is training-free: after five responses it fits the inclusive
  upper half of the current prompt's exponentiated rewards and stops at the
  gain/cost crossing. No training quantity enters the stopping decision.
- Coding fits one train-only isotonic map and one global upper-quarter
  shifted-exponential tail. One formula is used at every cost; utility uses
  `D_res = 0.85 D`. The former ten-row parameter table is gone.
- Coding target quality uses a frozen development inverse curve for that same
  one adaptive policy. It has no current-split blend, margin, interpolation,
  or mixture. A separate post-hoc Fixed-N comparator randomizes before
  generation only when needed to match aggregate adaptive accuracy exactly.

The exact algorithms and empirical discussion are in
`sections/ucb_pandora_algorithms.tex`.

## Rebuild experiment comparisons

The underlying final results are generated by:

```bash
bash codex_results/code/alignment_scripts/run_alignment_simple_final.sh
bash codex_results/code/coding_scripts/run_coding_simple_utility_final.sh
bash codex_results/code/coding_scripts/run_coding_simple_target_final.sh
```

Once those result folders exist, rebuild all manuscript oracle baselines,
tables, and figures from the repository root with:

```bash
MPLCONFIGDIR=/tmp/ucb_pandora_mpl \
  /home1/kalayci/env/bin/python \
  codex_results/ucb_pandora_manuscript/build_revised_benchmarks.py
```

`build_revised_benchmarks.py` replays the exact held-out fixed-policy streams,
verifies the train-selected Fixed-N values, adds the requested oracle Fixed-N
and character-budget baselines, adds equal-quality target diagnostics, and
writes its audit tables under
`artifacts/revised_benchmarks/`.

## Validation

From this directory:

```bash
PYTHONDONTWRITEBYTECODE=1 MPLCONFIGDIR=/tmp/ucb_pandora_mpl \
  /home1/kalayci/env/bin/python -m unittest -v test_revised_benchmarks.py

PYTHONDONTWRITEBYTECODE=1 /home1/kalayci/env/bin/python verify_claims.py

PYTHONDONTWRITEBYTECODE=1 MPLCONFIGDIR=/tmp/ucb_pandora_mpl \
  /home1/kalayci/env/bin/python verify_equations.py
```

The claim audit checks every displayed numerical result against the selected
simple-policy artifacts. The equation audit independently reproduces both
displayed stopping formulas and compares their decisions to the source code.

## Evaluation boundary

Alignment uses ten 50/50 splits of the same 100 prompts per generator. Coding
utility uses final split IDs 75--84 and target quality uses 95--104. Coding
development and final splits resample the same 83-problem cohort; this
within-corpus limitation is stated explicitly in the paper.
