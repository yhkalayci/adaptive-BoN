# Figure inventory

The revised manuscript uses five figures:

- `alignment/alignment_revised_baselines.pdf`: percentage relative utility
  improvement over train-selected Fixed-N, test-oracle Fixed-N, and the
  test-oracle character-budget allocation;
- `coding/coding_revised_baselines.pdf`: percentage relative utility
  improvement over train-selected Fixed-N, test-oracle Fixed-N, and a
  train-selected fixed character budget;
- `alignment/alignment_equal_cost_win_rate.pdf`: head-to-head win rate against
  independent Fixed-N at exactly matched expected characters;
- `alignment/alignment_target_quality_train_selected.pdf`: character saving
  plus adaptive and Fixed-N train-to-test target calibration;
- `coding/coding_target_quality_train_selected.pdf`: character saving plus
  adaptive and train-selected Fixed-N target calibration.

PNG copies are included for inspection. All five are generated by
`../build_revised_benchmarks.py` from the confirmed simple-policy evaluations
and exactly reconstructed fixed-policy curves. The coding equal-character
figure and other files remain as audit history and are not included by
`main.tex`.
